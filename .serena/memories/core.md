- Final typed ownership model:
  - `src/ta` — synchronous, runtime-independent TA domain. Owns `Kernel`, `PriorState`, `KernelStep` (`src/ta/kernel.rs`), the `Processor<K>` state owner (`src/ta/processor.rs`), indicator operator families under `src/ta/ops/**`, pure scalar gap-candidate detection (`src/ta/ops/gap_candidate.rs`), and `TaError`/`TaErrorKind`/`TaResult` (`src/ta/error.rs`). Candidate detection emits scalar facts only; it does not own prior-zone lists. Re-exports only TA errors at the `ta` module root; `src/ta/prelude.rs` exports the approved Kernel/Processor/error/indicator/state/named-input/factory/ATR-multiplier surface. `src/ta/**` imports no futures, Tokio, async, runtime, broadcast, channel, spawn, JoinError, Pin, or Stream token.
  - `src/adapter` — the only root module owning futures/Tokio stream concerns (`kernel_stream`, `kernel_stream_pipeline`, `broadcast_source`, `Stamped`, `StreamPipelineError`). `src/ta/**` remains synchronous and runtime-independent.
  - `src/engine` — owns the result frame: `SourceColumnData`, `SourceFrame`, `QueryResultFrame` (all in `src/engine/frame.rs`; re-exported from `src/engine/mod.rs:17`), `ComputedFrame` (`src/engine/traits.rs`), `ErrorKind`/`MarketError` (`src/engine/error.rs`), and `Ticker`/`ValidatedTicker` (`src/engine/validation.rs`). Note: names `ColumnData`, `OutputFrame`, `OwnedFrame` do not exist.
  - `src/query` — owns raw bounded prior-zone materialization from source frame data (`src/query/gap_zones.rs`) and optional DuckDB SQL projection over already-computed frames (`DuckDBQuery`, `FrameQuery`, `RawQuery`, session/invocation/vtab). Never compiles or executes TA computation.
  - `src/model` — leaf DTOs: `Kline`, `Timeframe`, `Direction`.
  - `src/ext` — outbound I/O adapters (bingx, yfinance, ntfy, webdriver).
  - `src/time_utils` — candle-timing helpers.
  - Application aggregates (`bins/cryptobot`, `bins/telegrambot`) own exactly one aggregate Kernel, aggregate state, **23-field** row DTO (`CryptoIndicatorRow`, `bins/cryptobot/src/presentation.rs:83–107`; fields 20–23 are the `gap_candidate_*` group added after initial design), and explicit projector in `src/presentation.rs`; they are the producers of `SourceFrame`. (Stale test name `u4_1_reuses_u1_owned_exact_19_field_row_and_fixed_periods` at line 1162 exercises all 23 fields — the name is stale, not the struct.)
- Data flow: applications build the aggregate Kernel + typed state, feed `Kline` rows through the adapter-owned `Processor<K>`, collect stamped typed rows, project an explicitly ordered application-owned `SourceFrame`, and optionally run `DuckDBQuery::project` (source-controlled SQL) into `QueryResultFrame`.

- Forward-projection capability (added post-initial design):
  - `bar_scheduled_close_ms(bar_open_ms: i64, tf: Timeframe) -> i64` (`src/time_utils.rs:231`) — scheduled exclusive close of a bar. Fixed-period addition for M1..D3 and W1 (`7*86_400_000 ms`). True UTC calendar-month advancement with day-of-month clamping for MOS1. **Do NOT use `Timeframe::weight()` for monthly** — it is a 30-day approximation only.
  - `iching_forecast_horizon(last_observed_open_ms: i64, tf: Timeframe, as_of: DateTime<Utc>) -> Vec<(i64, i64)>` (`src/time_utils.rs:295`) — 10 bars for the 12 sub-weekly TFs (M1..D3), 5 for W1, 2 for MOS1. Contiguous half-open pairs. Anchor-relative by design: timestamps derive from the last observed bar's open (BingX's W1 bar open time is not provable from this repo). Pure — `as_of` is injected, no ambient clock.
  - `IchingForecastBar`, `IchingRenderedPane3Values`, `materialize_iching_forecast`, `IchingForecastBar::rendered_pane3_values()` — `src/ta/iching/forecast.rs`; re-exported from `src/ta/mod.rs:15–16` and `src/ta/prelude.rs:5–6`.
  - Forecast reaches the chart as an optional per-TF `InteractiveDataset.forecast` sidecar (`bins/telegrambot/src/chart.rs:91`), accessed in the JS template as `dataset[tf]?.forecast` (line 763). `candlestickSeries.setData` throws on null OHLC — forecast records must never enter the `candles` array.
  - LLM receives the forecast via `{{iching_forecast}}` placeholder resolved in `render_prompt` (`bins/telegrambot/src/llm/mod.rs:879`). No dedicated LLM tool; registry is pinned at 7 by tests in `bins/telegrambot/src/llm/tools.rs:636`.
  - Single `as_of = Utc::now()` captured once at `bins/telegrambot/src/main.rs:173` (`scan_ticker`) and threaded to both chart and LLM paths — they cannot disagree on the horizon boundary.
  - Behavioural fact: the I-Ching cast changes only every 1–2 hours (measured: median 2h, never >2h over a 400-day hourly sample); the Mutual channel has only 16 reachable values. Short-TF projections are frequently flat; the chart discloses a "no cast change in this window" case.
